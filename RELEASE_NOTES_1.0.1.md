# Plataforma SST 1.0.1

Esta revisão substitui os hotfixes anteriores. Use o pacote completo desta versão.

Principais correções:

1. Tipagem completa do leitor ZIP de backups.
2. Restauração de questionários sem conflito entre tipos Prisma.
3. Conversão segura de campos JSON na restauração e geração de relatórios.
4. Dockerfile corrigido para `postinstall`, Prisma e build Next.js.
5. Configuração Railway Bucket ajustada para estilo virtual-hosted.
6. Docker Compose corrigido para execução integral da pilha.

Depois de substituir os arquivos, execute `git add .`, `git commit` e `git push`.
